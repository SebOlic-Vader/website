So bindest du das ZIP in deine Lernplattform ein
  1. Im Kurs oben rechts „Bearbeiten" einschalten.
  2. „Aktivität oder Material anlegen" → „Lernpaket" (SCORM) wählen.
  3. Das heruntergeladene ZIP in das Feld „Paketdatei" ziehen.
  4. Speichern — fertig. Das Paket öffnet sich direkt im Kurs und meldet den Fortschritt zurück.
Was passiert technisch?
Der Packer erzeugt ein SCORM-1.2-Paket (imsmanifest.xml + deine HTML als index.html). Fehlt in der HTML der SCORM-Code, wird automatisch eine SCORM-Brücke eingebaut: Sie meldet das Paket bei der Lernplattform an, setzt den Status auf „abgeschlossen" und speichert alles, was die Anwendung lokal ablegt (localStorage), zusätzlich im Kurs (cmi.suspend_data) — so bleibt der Bearbeitungsstand auch am anderen Rechner erhalten. Enthält die Datei schon eigenen SCORM-Code, wird sie unverändert verpackt. Ohne Lernplattform (z. B. beim Testen im Browser) funktioniert die Datei ganz normal weiter. Hinweis: SCORM 1.2 erlaubt max. 4096 Zeichen Speicherdaten; darüber bleibt der localStorage als Fallback aktiv. Extra für die Bewertungsübersicht: Schreibt die Anwendung ihren Fortschritt (0–100) in den localStorage-Schlüssel scormbridge_score, meldet die Brücke diesen Wert als Punktzahl an die Lernplattform.
